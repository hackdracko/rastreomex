# Rastreomex

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 16.2.1.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Code scaffolding

Run `ng generate component component-name` to generate a new component. You can also use `ng generate directive|pipe|service|class|guard|interface|enum|module`.

## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/rastreomex/browser` directory.

## Deploy (SEO/AI-friendly static HTML)

This is a single-page site prerendered with Angular Universal (`@nguniversal/express-engine`) so crawlers get fully-rendered HTML instead of an empty `<app-root>` shell.

Run `npm run prerender` and deploy the contents of `dist/rastreomex/browser` to any static host (Netlify, Vercel, Nginx, S3, etc.) — no Node server is required in production. `robots.txt` and `sitemap.xml` are copied to that folder automatically.
